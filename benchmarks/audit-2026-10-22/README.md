# Intermediate capacity-matched dataset

This completed 72-measurement run tested the bounded-CAS logger before the subsequent console/user integer-format and timing-boundary fixes. Its raw rows, source hashes, and guest transcripts are preserved as intermediate evidence. It is not presented as the final code's performance report.

Read the [final repeated comparison](../audit-final-2026-10-22/README.md) for current measurements and methodology. This directory is not a before/after speedup experiment: runtime changes and host variability prevent attributing differences to a single patch.
